# Stream D — Chat & Images Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Mumla's chat on a RecyclerView with off-main-thread HTML parsing, bounded/cached image thumbnails, a fullscreen tap-to-view image viewer with sharing, background image sending, image-stripped notifications and notification inline reply.

**Architecture:** A new `se.lublin.mumla.chat` package holds all logic as small, JVM-testable units: `ChatContentParser` turns an HTML body into a `ChatContent` (`Text` / `Image`) once per message and caches it on the `IChatMessage`; `ChatImageLoader` (coroutines) fetches `data:`/http(s) sources through `ImageSource`/`HttpImageFetcher`, decodes with `BoundedBitmapDecoder` and caches in an `LruCache`; `ChatAdapter` (`ListAdapter` + `DiffUtil`) renders three view types; `ImageViewerDialogFragment` shows a full-size decode in an in-repo `ZoomImageView` driven by a pure `ZoomState`; `OutgoingImagePreparer`/`OutgoingImageEncoder` prepare outgoing images on background dispatchers; `NotificationText` strips notifications and `MumlaMessageNotification` gains a `RemoteInput` reply action. `ChannelChatFragment` becomes thin Kotlin glue that re-syncs from `IMumlaService.getMessageLog()`.

**Tech Stack:** Kotlin, kotlinx-coroutines-android, AndroidX RecyclerView 1.4 (`ListAdapter`/`DiffUtil`), AndroidX core (`HtmlCompat`, `RemoteInput`, `FileProvider`, `ContextCompat`), lifecycle-runtime-ktx (`lifecycleScope`), Material 3 components, jsoup (notification stripping only), `android.util.LruCache`, `HttpURLConnection`, `ImageDecoder`. Tests: JUnit 4, Robolectric, Google Truth, kotlinx-coroutines-test, JDK `com.sun.net.httpserver.HttpServer` (no extra test dependency), PNG fixtures generated with `javax.imageio`.

**Spec:** `docs/superpowers/specs/2026-09-19-mumla-modernization.md` — §3.4 (D1–D6), §2 global constraints, §3 ownership table, §4 interfaces. Ownership note: `IChatMessage` belongs to stream D (spec §3 ownership table), so **stream A must not change it**; stream D, as its owner, adds exactly one additive property (`var content: ChatContent?`, Task 3). That property makes stream A's `ChatMessageLog` (500 entries) hold a reference to a `se.lublin.mumla.chat.ChatContent` — i.e. to an `android.text.Spanned` — per message; that D→A coupling is intentional and is what spec D1 means by "cached in the message model".

## Upstream facts checked for this plan (2026-09-19)

- Robolectric legacy graphics `ShadowBitmapFactory` (https://raw.githubusercontent.com/robolectric/robolectric/master/shadows/framework/src/main/java/org/robolectric/shadows/ShadowBitmapFactory.java): `decodeByteArray/decodeStream` read the real width/height of PNG bytes via `ImageIO`; `create(...)` divides width/height by `options.inSampleSize` and always sets `options.outWidth/outHeight`; it does **not** return `null` for `inJustDecodeBounds` (so production code reads `outWidth/outHeight` and ignores the return value); invalid data yields a fake bitmap unless the test calls `ShadowBitmapFactory.setAllowInvalidImageData(false)` (default `true`, reset after each test).
- Robolectric `ShadowLegacyBitmap`/`ImageUtil`: `Bitmap.getByteCount()` = width × height × 4 for ARGB_8888; `createScaledBitmap` tracks the destination size; `compress()` writes a real PNG/JPEG via `ImageIO`.
- Robolectric `ShadowImageDecoder` (https://raw.githubusercontent.com/robolectric/robolectric/master/shadows/framework/src/main/java/org/robolectric/shadows/ShadowImageDecoder.java): shadows the native `nCreate(InputStream…)`/`nCreate(ByteBuffer…)` calls, so `ImageDecoder.createSource(ContentResolver, Uri)` + `decodeBitmap(source, listener)` run the real framework Java; `nDecodeBitmap` scales the result to the requested target size (`setTargetSize` honored); `nGetSampledSize` throws `UnsupportedOperationException`, therefore production code must **not** call `setTargetSampleSize` and instead computes the sampled size itself and calls `setTargetSize`.
- Robolectric `ShadowContentResolver.registerInputStream(Uri, InputStream)` makes `contentResolver.openInputStream(uri)` return that stream.
- `subsampling-scale-image-view-androidx` (https://repo1.maven.org/maven2/com/davemorrissey/labs/subsampling-scale-image-view-androidx/maven-metadata.xml): only release 3.10.0, published 2020-01-05; last upstream commit 2020-12-30 (GitHub API); Apache-2.0. → Decision (spec D3): unmaintained for 5+ years and its tile subsampling is unnecessary because we decode bounded to the screen size; the plan uses an in-repo `ZoomState` (pure, ~60 lines) + `ZoomImageView` (~80 lines), under the ~150 line budget.
- Latest stable versions (for the dependency hook below): `androidx.lifecycle:lifecycle-runtime-ktx` 2.11.0 (https://dl.google.com/dl/android/maven2/androidx/lifecycle/group-index.xml), `org.jetbrains.kotlinx:kotlinx-coroutines-android` 1.11.0 (https://repo1.maven.org/maven2/org/jetbrains/kotlinx/kotlinx-coroutines-android/maven-metadata.xml), Robolectric 4.17, jsoup 1.23.2.

```kotlin
    private val LINK_PATTERN = Regex("(https?://\\S+)")

    /**
     * Decodes %XX escapes (UTF-8) and leaves everything else, including '+', untouched.
     * Mumble clients percent-encode base64 image data, which contains '+', so URLDecoder
     * (which turns '+' into a space) must not be used.
     */
    @JvmStatic
    fun percentDecode(input: String): String {
        if (!input.contains('%')) return input
        val out = StringBuilder(input.length)
        val pending = ByteArrayOutputStream()
        fun flush() {
            if (pending.size() > 0) {
                out.append(pending.toString("UTF-8"))
                pending.reset()
            }
        }
        var i = 0
        while (i < input.length) {
            val c = input[i]
            val byte = if (c == '%' && i + 2 < input.length) hexByte(input[i + 1], input[i + 2]) else null
            if (byte != null) {
                pending.write(byte)
                i += 3
            } else {
                flush()
                out.append(c)
                i += 1
            }
        }
        flush()
        return out.toString()
    }

    /** Adds HTML markup to an outgoing message: links become anchors, newlines become `<br>`. */
    @JvmStatic
    fun markupOutgoingMessage(message: String): String =
        LINK_PATTERN.replace(message) { "<a href=\"${it.value}\">${it.value}</a>" }
            .replace("\n", "<br>")

    private fun hexByte(hi: Char, lo: Char): Int? {
        val h = Character.digit(hi, 16)
        val l = Character.digit(lo, 16)
        return if (h < 0 || l < 0) null else (h shl 4) or l
    }
```

```kotlin
/** The parsed body of one chat message. Parsed once per message and cached on the message. */
```

```kotlin
import android.text.Spanned
import android.text.style.ImageSpan
import androidx.core.text.HtmlCompat

/**
 * Parses Mumble HTML message bodies into [ChatContent]. Pure CPU work, safe to call from any thread.
 * `HtmlCompat.fromHtml` inserts an [ImageSpan] per `<img>`, which is what this parser splits on.
 *
 * The four-argument overload is used on purpose: without an image getter AOSP's
 * `HtmlToSpannedConverter.startImg` falls back to `Resources.getSystem().getDrawable(unknown_image)`
 * and calls `setBounds` on it for every `<img>`, i.e. it loads and mutates a framework drawable that
 * is thrown away immediately — on a background thread. The trivial getter below avoids that and
 * keeps the `ImageSpan`'s `source` intact, which is all this parser reads.
 */
class ChatContentParser(private val imagePlaceholder: String) {

    fun parse(html: String): ChatContent {
        val spanned = HtmlCompat.fromHtml(html, HtmlCompat.FROM_HTML_MODE_LEGACY, PLACEHOLDER_IMAGES, null)
        val builder = SpannableStringBuilder(spanned)
        val images = builder.getSpans(0, builder.length, ImageSpan::class.java)
            .sortedBy { builder.getSpanStart(it) }
        if (images.isEmpty()) return ChatContent.Text(spanned)

        val first = images.first()
        val start = builder.getSpanStart(first)
        val end = builder.getSpanEnd(first)
        val before = trimmed(builder.subSequence(0, start))
        val after = trimmed(replacePlaceholders(SpannableStringBuilder(builder.subSequence(end, builder.length))))
        return ChatContent.Image(first.source ?: "", before, after)
    }

    private fun replacePlaceholders(text: SpannableStringBuilder): SpannableStringBuilder {
        for (span in text.getSpans(0, text.length, ImageSpan::class.java)) {
            val s = text.getSpanStart(span)
            val e = text.getSpanEnd(span)
            text.removeSpan(span)
            text.replace(s, e, imagePlaceholder)
        }
        return text
    }

    private fun trimmed(text: CharSequence): Spanned? {
        var s = 0
        var e = text.length
        while (s < e && text[s].isWhitespace()) s++
        while (e > s && text[e - 1].isWhitespace()) e--
        return if (s == e) null else SpannableStringBuilder(text, s, e)
    }

    private companion object {
        /** A 1x1 transparent drawable, so no framework drawable is loaded per `<img>`. */
        val PLACEHOLDER_IMAGES = Html.ImageGetter {
            ColorDrawable(Color.TRANSPARENT).apply { setBounds(0, 0, 1, 1) }
        }
    }
}
```

```kotlin
package se.lublin.mumla.chat

import se.lublin.mumla.util.HtmlUtils
import java.util.Base64

enum class ImageError { UNSUPPORTED, MALFORMED, TOO_LARGE, NETWORK, TIMEOUT, EXTERNAL_DISABLED }

class ImageFetchException(val error: ImageError, cause: Throwable? = null) : Exception(error.name, cause)

/** Where the bytes of an `<img src>` come from. */
sealed class ImageSource {
    class Data(val bytes: ByteArray) : ImageSource()
    data class Remote(val url: String) : ImageSource()
    object Unsupported : ImageSource()

    companion object {
        private const val DATA_PREFIX = "data:image"
        private const val BASE64_MARKER = ";base64"

        /**
         * Classifies [source] (trimmed, raw). Percent decoding is applied **only** to `data:` URIs,
         * because Mumble clients percent-encode the base64 payload they send. A remote URL is passed
         * through untouched: decoding it would destroy legitimate escapes (`%20` would become a space,
         * which `URI(url)` then rejects, and `%2F` would silently change the path).
         */
        fun parse(source: String): ImageSource {
            val trimmed = source.trim()
            return when {
                trimmed.startsWith(DATA_PREFIX, ignoreCase = true) -> parseData(HtmlUtils.percentDecode(trimmed))
                trimmed.startsWith("http://", ignoreCase = true) ||
                    trimmed.startsWith("https://", ignoreCase = true) -> Remote(trimmed)
                else -> Unsupported
            }
        }

        private fun parseData(uri: String): ImageSource {
            val comma = uri.indexOf(',')
            if (comma < 0) return Unsupported
            if (!uri.substring(0, comma).endsWith(BASE64_MARKER, ignoreCase = true)) return Unsupported
            return try {
                Data(Base64.getMimeDecoder().decode(uri.substring(comma + 1)))
            } catch (e: IllegalArgumentException) {
                Unsupported
            }
        }
    }
}
```

```kotlin
package se.lublin.mumla.chat

import java.io.ByteArrayOutputStream
import java.io.IOException
import java.io.InputStream
import java.net.HttpURLConnection
import java.net.MalformedURLException
import java.net.SocketTimeoutException
import java.net.URI
import java.net.URISyntaxException

/** Fetches raw image bytes for a URL. Blocking; call from an IO dispatcher. */
fun interface ImageFetcher {
    @Throws(ImageFetchException::class)
    fun fetch(url: String): ByteArray
}

class HttpImageFetcher(
    private val connectTimeoutMs: Int = 5_000,
    private val readTimeoutMs: Int = 10_000,
    private val maxBytes: Long = 5L * 1024 * 1024,
) : ImageFetcher {

    override fun fetch(url: String): ByteArray {
        val connection = try {
            URI(url).toURL().openConnection() as? HttpURLConnection
                ?: throw ImageFetchException(ImageError.UNSUPPORTED)
        } catch (e: URISyntaxException) {
            throw ImageFetchException(ImageError.UNSUPPORTED, e)
        } catch (e: IllegalArgumentException) {
            // URI.toURL() on a relative URI, e.g. "nourl".
            throw ImageFetchException(ImageError.UNSUPPORTED, e)
        } catch (e: MalformedURLException) {
            // URI.toURL() on an absolute URI with a scheme the JDK has no handler for, e.g. "ftp://".
            // MalformedURLException is an IOException, so this catch must come first.
            throw ImageFetchException(ImageError.UNSUPPORTED, e)
        } catch (e: IOException) {
            throw ImageFetchException(ImageError.NETWORK, e)
        }
        try {
            connection.connectTimeout = connectTimeoutMs
            connection.readTimeout = readTimeoutMs
            connection.instanceFollowRedirects = true
            if (connection.responseCode !in 200..299) throw ImageFetchException(ImageError.NETWORK)
            if (connection.contentLengthLong > maxBytes) throw ImageFetchException(ImageError.TOO_LARGE)
            return connection.inputStream.use { readCapped(it) }
        } catch (e: SocketTimeoutException) {
            throw ImageFetchException(ImageError.TIMEOUT, e)
        } catch (e: IOException) {
            throw ImageFetchException(ImageError.NETWORK, e)
        } finally {
            connection.disconnect()
        }
    }

    private fun readCapped(input: InputStream): ByteArray {
        val out = ByteArrayOutputStream()
        val buffer = ByteArray(16 * 1024)
        while (true) {
            val n = input.read(buffer)
            if (n < 0) break
            if (out.size() + n > maxBytes) throw ImageFetchException(ImageError.TOO_LARGE)
            out.write(buffer, 0, n)
        }
        return out.toByteArray()
    }
}
```

- [ ] **Step 8: Record the cleartext decision (no code change)**

`HttpImageFetcherTest` runs on the plain JVM, where `http://` works. **On device it does not:**
`app/src/main/AndroidManifest.xml` declares neither `android:usesCleartextTraffic` nor
`android:networkSecurityConfig`, and `targetSdk = 36`, so the platform blocks cleartext. An
`ImageSource.Remote("http://…")` therefore fails with an `IOException` that `fetch` maps to
`ImageError.NETWORK`, and the chat UI shows the generic image-failure state.

That is the intended behavior for this plan: chat images are attacker-controlled URLs from a chat
server, and opting the whole app back into cleartext to render them is not a trade this stream
makes. Do **not** add `android:usesCleartextTraffic="true"`. If cleartext image loading is wanted
later it needs a scoped `res/xml/network_security_config.xml`, which is a change to
`AndroidManifest.xml` and therefore stream P's call (spec §3 ownership table).

```kotlin
object BitmapUtils {
    /** Scales [image] down so it fits within [maxWidth] x [maxHeight] keeping the aspect ratio; never upscales. */
    @JvmStatic
    fun resizeKeepingAspect(image: Bitmap, maxWidth: Int, maxHeight: Int): Bitmap {
        val width = image.width
        val height = image.height
        if (width <= maxWidth && height <= maxHeight) return image

        val ratioBitmap = width.toFloat() / height.toFloat()
        val ratioMax = maxWidth.toFloat() / maxHeight.toFloat()

        val finalHeight: Int

        } else {
            finalWidth = maxWidth
            finalHeight = (maxWidth / ratioBitmap).toInt().coerceAtLeast(1)
        }
        return Bitmap.createScaledBitmap(image, finalWidth, finalHeight, true)
    }
}
```

```kotlin
package se.lublin.mumla.chat

import android.graphics.Bitmap
import android.graphics.BitmapFactory
import se.lublin.mumla.util.BitmapUtils

/** Memory-bounded decoding: a bounds pass, a power-of-two `inSampleSize`, then an exact fit. */
object BoundedBitmapDecoder {

    /**
     * Largest power-of-two sample size whose result is still at or above the aspect-fitted target
     * size. Sampling toward the fitted target (not toward the raw bounds on both axes) is what makes
     * an extreme aspect ratio, e.g. 12000 x 200 into a 240 x 240 box, sample down at all.
     */
    fun sampleSizeFor(width: Int, height: Int, maxWidth: Int, maxHeight: Int): Int {
        if (width <= 0 || height <= 0) return 1
        val fit = minOf(maxWidth / width.toFloat(), maxHeight / height.toFloat()).coerceAtMost(1f)
        var sample = 1
        while (1f / (sample * 2) >= fit) sample *= 2
        return sample
    }

    /** Decodes [bytes] to a bitmap no larger than [maxWidth] x [maxHeight] (aspect kept); null if not an image. */
    fun decode(bytes: ByteArray, maxWidth: Int, maxHeight: Int): Bitmap? {
        val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
        BitmapFactory.decodeByteArray(bytes, 0, bytes.size, bounds)
        if (bounds.outWidth <= 0 || bounds.outHeight <= 0) return null

        val options = BitmapFactory.Options().apply {
            inSampleSize = sampleSizeFor(bounds.outWidth, bounds.outHeight, maxWidth, maxHeight)
        }
        val decoded = BitmapFactory.decodeByteArray(bytes, 0, bytes.size, options) ?: return null
        return BitmapUtils.resizeKeepingAspect(decoded, maxWidth, maxHeight)
    }
}
```

1. **The thumbnail cache is keyed by source *and* bounds** (`cacheKey(source) + ":" + w + "x" + h`),
   so a caller asking for 120 dp does not get the 240 dp bitmap the adapter put there first.
   `cacheKey(source)` itself stays source-only — `ImageShareExporter` (Task 8) uses it as a file name.
2. **Only terminal failures are cached forever** (`UNSUPPORTED`, `MALFORMED`, `TOO_LARGE`).
   `NETWORK` and `TIMEOUT` are transient — one image fetched while the phone was offline must not be
   unloadable for the rest of the process lifetime — so they get a 30 s TTL. `EXTERNAL_DISABLED` is
   not cached at all (the setting can change).
3. **Concurrent loads of the same key share one fetch+decode.** A fling that binds the same `data:`
   URI in several rows, or a rebind after rotation, otherwise starts one decode per bind.

`fetchBytes` additionally keeps the **last** fetched byte array (one entry, ≤ the fetcher's 5 MiB
cap), so the viewer's share action in Task 8 does not re-download the image it just displayed.

```kotlin
package se.lublin.mumla.chat

import android.content.Context
import android.graphics.Bitmap
import android.util.LruCache
import androidx.annotation.VisibleForTesting
import kotlinx.coroutines.CompletableDeferred
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.coroutines.withContext
import se.lublin.mumla.Settings
import java.security.MessageDigest

sealed class ImageResult {
    class Ready(val bitmap: Bitmap) : ImageResult()
    data class Failed(val error: ImageError) : ImageResult()
}

/**
 * Loads chat images off the main thread.
 *
 * Thumbnails are cached in an [LruCache] keyed by the SHA-1 of the source **and the requested
 * bounds**, so callers asking for different sizes do not steal each other's bitmaps; the budget
 * defaults to 1/8 of the max heap. Failures are cached too, but only terminal ones
 * ([ImageError.UNSUPPORTED], [ImageError.MALFORMED], [ImageError.TOO_LARGE]) for good:
 * [ImageError.NETWORK] and [ImageError.TIMEOUT] expire after [TRANSIENT_ERROR_TTL_MS] so an image
 * fetched while offline becomes loadable again, and [ImageError.EXTERNAL_DISABLED] is never cached
 * because the setting behind it can change.
 *
 * Concurrent loads of the same key share one fetch+decode, so a RecyclerView fling that binds the
 * same source in several rows does the work once.
 */
class ChatImageLoader(
    private val fetcher: ImageFetcher = HttpImageFetcher(),
    private val externalImagesAllowed: () -> Boolean,
    maxCacheBytes: Long = Runtime.getRuntime().maxMemory() / 8,
    private val ioDispatcher: CoroutineDispatcher = Dispatchers.IO,
    private val decodeDispatcher: CoroutineDispatcher = Dispatchers.Default,
    private val nowMillis: () -> Long = System::currentTimeMillis,
) {
    private class Entry(val result: ImageResult, val expiresAtMillis: Long)

    private val cache = object : LruCache<String, Entry>((maxCacheBytes / 1024).toInt().coerceAtLeast(1)) {
        override fun sizeOf(key: String, value: Entry): Int = when (val result = value.result) {
            is ImageResult.Ready -> (result.bitmap.byteCount / 1024).coerceAtLeast(1)
            is ImageResult.Failed -> 1
        }
    }

    private val lock = Mutex()
    private val inFlight = mutableMapOf<String, CompletableDeferred<ImageResult>>()

    private val bytesLock = Mutex()
    /** The most recently fetched source and its bytes, so the viewer's share action can reuse them. */
    private var lastBytes: Pair<String, ByteArray>? = null

    /** Thumbnail bounded by [maxWidth] x [maxHeight] px; cached per source *and* bounds. */
    suspend fun loadThumbnail(source: String, maxWidth: Int, maxHeight: Int): ImageResult {
        val key = thumbnailKey(source, maxWidth, maxHeight)
        cached(key)?.let { return it }

        // Never await while holding the mutex: the owning coroutine needs it to publish the result.
        val (owned, job) = lock.withLock {
            val running = inFlight[key]
            if (running != null) {
                false to running
            } else {
                val fresh = CompletableDeferred<ImageResult>()
                inFlight[key] = fresh
                true to fresh
            }
        }
        if (!owned) return job.await()

        val result = try {
            load(source, maxWidth, maxHeight)
        } catch (t: Throwable) {
            lock.withLock { inFlight.remove(key) }
            job.completeExceptionally(t)
            throw t
        }
        lock.withLock {
            inFlight.remove(key)
            ttlMillisFor(result)?.let { ttl ->
                val expiry = if (ttl == Long.MAX_VALUE) Long.MAX_VALUE else nowMillis() + ttl
                cache.put(key, Entry(result, expiry))
            }
        }
        job.complete(result)
        return result
    }

    /** Decode bounded by the given size (e.g. the screen); never cached as a bitmap. */
    suspend fun loadFull(source: String, maxWidth: Int, maxHeight: Int): ImageResult =
        load(source, maxWidth, maxHeight)

    /**
     * Raw bytes of [source]. Throws [ImageFetchException]. Runs on [ioDispatcher].
     * Remembers the last result (one entry) so displaying an image and then sharing it does not
     * download it twice.
     */
    suspend fun fetchBytes(source: String): ByteArray {
        val key = cacheKey(source)
        bytesLock.withLock { lastBytes?.takeIf { it.first == key }?.second }?.let { return it }
        val bytes = withContext(ioDispatcher) {
            when (val parsed = ImageSource.parse(source)) {
                is ImageSource.Data -> parsed.bytes
                is ImageSource.Remote -> {
                    if (!externalImagesAllowed()) throw ImageFetchException(ImageError.EXTERNAL_DISABLED)
                    fetcher.fetch(parsed.url)
                }
                ImageSource.Unsupported -> throw ImageFetchException(ImageError.UNSUPPORTED)
            }
        }
        bytesLock.withLock { lastBytes = key to bytes }
        return bytes
    }

    private fun cached(key: String): ImageResult? {
        val entry = cache.get(key) ?: return null
        if (entry.expiresAtMillis <= nowMillis()) {
            cache.remove(key)
            return null
        }
        return entry.result
    }

    /** How long [result] may be served from the cache; `null` means do not cache it at all. */
    private fun ttlMillisFor(result: ImageResult): Long? = when {
        result is ImageResult.Failed && result.error == ImageError.EXTERNAL_DISABLED -> null
        result is ImageResult.Failed &&
            (result.error == ImageError.NETWORK || result.error == ImageError.TIMEOUT) -> TRANSIENT_ERROR_TTL_MS
        else -> Long.MAX_VALUE
    }

    private suspend fun load(source: String, maxWidth: Int, maxHeight: Int): ImageResult {
        val bytes = try {
            fetchBytes(source)
        } catch (e: ImageFetchException) {
            return ImageResult.Failed(e.error)
        }
        val bitmap = withContext(decodeDispatcher) { BoundedBitmapDecoder.decode(bytes, maxWidth, maxHeight) }
        return if (bitmap == null) ImageResult.Failed(ImageError.MALFORMED) else ImageResult.Ready(bitmap)
    }

    private fun thumbnailKey(source: String, maxWidth: Int, maxHeight: Int): String =
        cacheKey(source) + ":" + maxWidth + "x" + maxHeight

    companion object {
        /** How long a NETWORK/TIMEOUT failure stays cached before the source is tried again. */
        const val TRANSIENT_ERROR_TTL_MS = 30_000L

        /** Stable, filesystem-safe key for a source; also used as the share file name (Task 8). */
        fun cacheKey(source: String): String =
            MessageDigest.getInstance("SHA-1")
                .digest(source.toByteArray(Charsets.UTF_8))
                .joinToString("") { "%02x".format(it) }
    }
}
```

```kotlin
package se.lublin.mumla.chat

import android.graphics.Matrix

/**
 * Zoom/pan state of an image that is fit-centered in a view. [scale] is relative to the fit
 * scale (1 = fits the view), [tx]/[ty] are offsets in view pixels from the centered position.
 */
data class ZoomState(val scale: Float = 1f, val tx: Float = 0f, val ty: Float = 0f) {

    /** Scales by [factor] keeping the image point under ([focusX], [focusY]) fixed. */
    fun scaledBy(factor: Float, focusX: Float, focusY: Float, viewWidth: Float, viewHeight: Float): ZoomState {
        val newScale = (scale * factor).coerceIn(MIN_SCALE, MAX_SCALE)
        val k = newScale / scale
        val cx = viewWidth / 2f
        val cy = viewHeight / 2f
        return ZoomState(newScale, (focusX - cx) * (1 - k) + tx * k, (focusY - cy) * (1 - k) + ty * k)
    }

    fun pannedBy(dx: Float, dy: Float): ZoomState = copy(tx = tx + dx, ty = ty + dy)

    /** Keeps the image covering the view on axes where it is larger, centered where it is smaller. */
    fun clamped(viewWidth: Float, viewHeight: Float, imageWidth: Float, imageHeight: Float): ZoomState {
        val s = fitScale(viewWidth, viewHeight, imageWidth, imageHeight) * scale
        return copy(tx = clampAxis(tx, imageWidth * s, viewWidth), ty = clampAxis(ty, imageHeight * s, viewHeight))
    }

    fun toMatrix(viewWidth: Float, viewHeight: Float, imageWidth: Float, imageHeight: Float): Matrix {
        val s = fitScale(viewWidth, viewHeight, imageWidth, imageHeight) * scale
        return Matrix().apply {
            setScale(s, s)
            postTranslate((viewWidth - imageWidth * s) / 2f + tx, (viewHeight - imageHeight * s) / 2f + ty)
        }
    }

    private fun clampAxis(offset: Float, displayed: Float, view: Float): Float {
        val slack = (displayed - view) / 2f
        return if (slack <= 0f) 0f else offset.coerceIn(-slack, slack)
    }

    companion object {
        const val MIN_SCALE = 1f
        const val MAX_SCALE = 5f

        fun fitScale(viewWidth: Float, viewHeight: Float, imageWidth: Float, imageHeight: Float): Float =
            minOf(viewWidth / imageWidth, viewHeight / imageHeight)
    }
}
```

```kotlin
import android.util.AttributeSet

import androidx.appcompat.widget.AppCompatImageView

/** An ImageView with pinch-zoom, drag and double-tap, driven by [ZoomState]. */
class ZoomImageView @JvmOverloads constructor(
    context: Context,
    attrs: AttributeSet? = null,
) : AppCompatImageView(context, attrs) {

    var state = ZoomState()
        private set

    private val scaleDetector = ScaleGestureDetector(context, object : ScaleGestureDetector.SimpleOnScaleGestureListener() {
        override fun onScale(detector: ScaleGestureDetector): Boolean {
            zoomBy(detector.scaleFactor, detector.focusX, detector.focusY)
            return true
        }
    })

    private val gestureDetector = GestureDetector(context, object : GestureDetector.SimpleOnGestureListener() {
        override fun onDown(e: MotionEvent): Boolean = true

        override fun onScroll(e1: MotionEvent?, e2: MotionEvent, distanceX: Float, distanceY: Float): Boolean {
            panBy(-distanceX, -distanceY)
            return true
        }

        override fun onDoubleTap(e: MotionEvent): Boolean {
            zoomBy(if (state.scale > 1f) 1f / state.scale else DOUBLE_TAP_SCALE, e.x, e.y)
            return true
        }

        override fun onSingleTapConfirmed(e: MotionEvent): Boolean {
            performClick()
            return true
        }
    })

    init {
        scaleType = ScaleType.MATRIX
    }

    override fun onTouchEvent(event: MotionEvent): Boolean {
        scaleDetector.onTouchEvent(event)
        gestureDetector.onTouchEvent(event)
        return true
    }

    override fun performClick(): Boolean = super.performClick()

    override fun setImageBitmap(bm: Bitmap?) {
        super.setImageBitmap(bm)
        state = ZoomState()
        applyState()
    }

    override fun onSizeChanged(w: Int, h: Int, oldw: Int, oldh: Int) {
        super.onSizeChanged(w, h, oldw, oldh)
        applyState()
    }

    fun zoomBy(factor: Float, focusX: Float, focusY: Float) {
        state = state.scaledBy(factor, focusX, focusY, width.toFloat(), height.toFloat())
        applyState()
    }

    fun panBy(dx: Float, dy: Float) {
        state = state.pannedBy(dx, dy)
        applyState()
    }

    private fun applyState() {
        val d = drawable ?: return
        if (width == 0 || height == 0 || d.intrinsicWidth <= 0 || d.intrinsicHeight <= 0) return
        val vw = width.toFloat()
        val vh = height.toFloat()
        val iw = d.intrinsicWidth.toFloat()
        val ih = d.intrinsicHeight.toFloat()
        state = state.clamped(vw, vh, iw, ih)
        imageMatrix = state.toMatrix(vw, vh, iw, ih)
    }

    private companion object {
        const val DOUBLE_TAP_SCALE = 2.5f
    }
}
```

```kotlin
package se.lublin.mumla.chat

import android.content.Context
import android.net.Uri
import androidx.core.content.FileProvider
import java.io.File

/** Writes image bytes into the app cache and exposes them through the app's FileProvider. */
class ImageShareExporter(private val context: Context) {

    data class Exported(val uri: Uri, val mimeType: String)

    fun export(source: String, bytes: ByteArray): Exported {
        val (extension, mimeType) = typeOf(bytes)
        val dir = File(context.cacheDir, DIRECTORY).apply { mkdirs() }
        prune(dir)
        val file = File(dir, ChatImageLoader.cacheKey(source) + "." + extension)
        file.outputStream().use { it.write(bytes) }
        return Exported(FileProvider.getUriForFile(context, context.packageName + AUTHORITY_SUFFIX, file), mimeType)
    }

    /**
     * This directory is a staging area for the share sheet, not a cache: nothing ever deletes the
     * files again, so drop everything older than [MAX_AGE_MS] whenever a new share is prepared.
     */
    private fun prune(dir: File) {
        val cutoff = System.currentTimeMillis() - MAX_AGE_MS
        dir.listFiles()?.forEach { if (it.isFile && it.lastModified() < cutoff) it.delete() }
    }

    companion object {
        const val DIRECTORY = "shared_images"
        const val AUTHORITY_SUFFIX = ".fileprovider"
        const val MAX_AGE_MS = 24L * 60 * 60 * 1000

        /** (file extension, MIME type) from magic bytes. */
        fun typeOf(bytes: ByteArray): Pair<String, String> = when {
            bytes.startsWith(0x89, 0x50, 0x4E, 0x47) -> "png" to "image/png"
            bytes.startsWith(0xFF, 0xD8) -> "jpg" to "image/jpeg"
            bytes.startsWith('G'.code, 'I'.code, 'F'.code) -> "gif" to "image/gif"
            bytes.startsWith('R'.code, 'I'.code, 'F'.code, 'F'.code) && bytes.size >= 12 &&
                bytes[8] == 'W'.code.toByte() && bytes[9] == 'E'.code.toByte() &&
                bytes[10] == 'B'.code.toByte() && bytes[11] == 'P'.code.toByte() -> "webp" to "image/webp"
            else -> "bin" to "application/octet-stream"
        }

        private fun ByteArray.startsWith(vararg prefix: Int): Boolean =
            size >= prefix.size && prefix.indices.all { this[it] == prefix[it].toByte() }
    }
}
```

```kotlin
import android.content.ClipData
import android.content.Intent
import android.os.Bundle
import android.view.LayoutInflater

import android.view.ViewGroup
import android.widget.TextView

import androidx.fragment.app.DialogFragment
import androidx.lifecycle.lifecycleScope
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext
import se.lublin.mumla.R
import java.io.IOException

/** Fullscreen viewer for one chat image; decodes for the screen size off the main thread. */
class ImageViewerDialogFragment : DialogFragment() {

    /** Test seam: the dispatcher the share export runs on. Production code must not set this. */
    @VisibleForTesting
    internal var ioDispatcher: CoroutineDispatcher = Dispatchers.IO

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setStyle(STYLE_NO_FRAME, R.style.Theme_Mumla_ImageViewer)
    }

    override fun onCreateView(inflater: LayoutInflater, container: ViewGroup?, savedInstanceState: Bundle?): View =
        inflater.inflate(R.layout.dialog_image_viewer, container, false)

    override fun onStart() {
        super.onStart()
        dialog?.window?.setLayout(ViewGroup.LayoutParams.MATCH_PARENT, ViewGroup.LayoutParams.MATCH_PARENT)
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)
        val source = requireArguments().getString(ARG_SOURCE) ?: return dismiss()
        val image: ZoomImageView = view.findViewById(R.id.image_viewer_image)
        val progress: View = view.findViewById(R.id.image_viewer_progress)
        val status: TextView = view.findViewById(R.id.image_viewer_status)
        val share: View = view.findViewById(R.id.image_viewer_share)
        view.findViewById<View>(R.id.image_viewer_close).setOnClickListener { dismiss() }
        share.isEnabled = false
        share.setOnClickListener { shareImage(source) }

        val metrics = resources.displayMetrics
        viewLifecycleOwner.lifecycleScope.launch {
            val result = ChatImageLoaders.get(requireContext()).loadFull(source, metrics.widthPixels, metrics.heightPixels)
            progress.visibility = View.GONE
            when (result) {
                is ImageResult.Ready -> {
                    image.setImageBitmap(result.bitmap)
                    share.isEnabled = true
                }
                is ImageResult.Failed -> {
                    status.text = getString(R.string.chat_image_load_failed)
                    status.visibility = View.VISIBLE
                }
            }
        }
    }

    private fun shareImage(source: String) {
        val context = requireContext()
        viewLifecycleOwner.lifecycleScope.launch {
            val exported = try {
                withContext(ioDispatcher) {
                    val bytes = ChatImageLoaders.get(context).fetchBytes(source)
                    ImageShareExporter(context).export(source, bytes)
                }
            } catch (e: ImageFetchException) {
                Toast.makeText(context, R.string.chat_image_load_failed, Toast.LENGTH_SHORT).show()
                return@launch
            } catch (e: IOException) {
                Toast.makeText(context, R.string.chat_image_load_failed, Toast.LENGTH_SHORT).show()
                return@launch
            }
            // The URI must travel as ClipData, not only as EXTRA_STREAM: Intent.createChooser
            // migrates FLAG_GRANT_READ_URI_PERMISSION to the chooser only for the intent's data or
            // ClipData, so without this the receiver gets a SecurityException on openInputStream.
            val send = Intent(Intent.ACTION_SEND)
                .setType(exported.mimeType)
                .putExtra(Intent.EXTRA_STREAM, exported.uri)
                .addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
            send.clipData = ClipData.newRawUri(null, exported.uri)
            val chooser = Intent.createChooser(send, getString(R.string.chat_image_share))
                .addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
            startActivity(chooser)
        }
    }

    companion object {
        const val TAG = "image_viewer"

        @VisibleForTesting
        internal const val ARG_SOURCE = "source"

        fun newInstance(source: String): ImageViewerDialogFragment = ImageViewerDialogFragment().apply {
            arguments = Bundle().apply { putString(ARG_SOURCE, source) }
        }
    }
}
```

### Task 9: ChatAdapter — RecyclerView list with DiffUtil and off-main-thread parsing

Spec D1. This task builds the adapter and its layouts; Task 11 puts it into the fragment.

**Files:**
- Create: `app/src/main/java/se/lublin/mumla/chat/ChatAdapter.kt`
- Create: `app/src/main/res/layout/list_chat_item_image.xml`
- Modify: `app/src/main/res/layout/list_chat_item.xml` (root `CardView` height fix + row spacing)
- Modify: `app/src/main/res/values/dimens.xml` (append two dimens), `app/src/main/res/values/strings.xml` (append one string)
- Test: `app/src/test/java/se/lublin/mumla/chat/ChatAdapterTest.kt`

**Interfaces:**
- Consumes: `ChatContent`, `ChatContentParser` (Task 2), `IChatMessage.content` (Task 3), `ChatImageLoader`, `ImageResult` (Task 6), `se.lublin.humla.model.IMessage`.
- Produces:
  `class ChatAdapter(parser: ChatContentParser, loader: ChatImageLoader, thumbnailPx: Int, selfSessionId: () -> Int, onImageClicked: (String) -> Unit, scope: CoroutineScope, parseDispatcher: CoroutineDispatcher = Dispatchers.Default, differConfig: AsyncDifferConfig<IChatMessage> = AsyncDifferConfig.Builder(DIFF).build()) : ListAdapter<IChatMessage, ChatAdapter.Holder> { suspend fun submitMessages(messages: List<IChatMessage>) }`,
  `sealed class ChatAdapter.Holder`, `ChatAdapter.TextHolder`, `ChatAdapter.ImageHolder`,
  `companion { const val TYPE_TEXT = 0; TYPE_INFO = 1; TYPE_IMAGE = 2; val DIFF }`.

Design decisions this task makes:

- **Parsing happens before `submitList`, not during bind.** `getItemViewType` is synchronous and has
  to know whether a message contains an image, which only the parse result tells it. So
  `submitMessages` is a `suspend` function that fills `IChatMessage.content` on `parseDispatcher`
  and only then hands the list to `ListAdapter`. `submitList` is never called directly.
- **`DiffUtil` compares by identity.** Stream A's message log appends immutable `IChatMessage`
  instances and never edits one, so `===` is both the item identity and the content check, and
  re-submitting a list rebinds nothing. There are no change payloads for the same reason.
- **Thumbnail jobs belong to the holder.** Each `ImageHolder` keeps its `Job`; binding cancels the
  previous one and `onViewRecycled` cancels and clears the drawable, so a fling cannot land a
  bitmap in the wrong row.

```kotlin
 * [submitMessages]. Diffing is by identity because the message log appends immutable instances.

class ChatAdapter(

    private val loader: ChatImageLoader,
    private val thumbnailPx: Int,
    private val selfSessionId: () -> Int,
    private val onImageClicked: (String) -> Unit,

    private val timeFormat: DateFormat = DateFormat.getTimeInstance()

    /**
     * Parses every message that has no [IChatMessage.content] yet on [parseDispatcher], then submits
     * the list on the caller's (main) thread. The only entry point: calling `submitList` directly
     * would let [getItemViewType] see an unparsed message.
     */
    suspend fun submitMessages(messages: List<IChatMessage>) {
        val snapshot = messages.toList()
        withContext(parseDispatcher) {
            for (message in snapshot) {
                if (message.content == null) message.content = parser.parse(message.body)
            }
        }
        submitList(snapshot)
    }

    override fun getItemViewType(position: Int): Int {
        val message = getItem(position)
        return when {
            message.content is ChatContent.Image -> TYPE_IMAGE
            message is IChatMessage.InfoMessage -> TYPE_INFO
            else -> TYPE_TEXT
        }
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): Holder {
        val inflater = LayoutInflater.from(parent.context)
        return if (viewType == TYPE_IMAGE) {
            ImageHolder(inflater.inflate(R.layout.list_chat_item_image, parent, false))
        } else {
            TextHolder(inflater.inflate(R.layout.list_chat_item, parent, false))
        }
    }

    override fun onBindViewHolder(holder: Holder, position: Int) {
        val message = getItem(position)
        holder.time.text = timeFormat.format(Date(message.receivedTime))
        bindHeader(holder, message)
        when (holder) {
            is TextHolder -> holder.text.apply {
                text = (message.content as? ChatContent.Text)?.spanned ?: message.body
                gravity = holder.box.gravity
                movementMethod = LinkMovementMethod.getInstance()
            }
            is ImageHolder -> bindImage(holder, message.content as ChatContent.Image)
        }
    }

    override fun onViewRecycled(holder: Holder) {
        if (holder is ImageHolder) {
            holder.job?.cancel()
            holder.job = null
            holder.image.setImageDrawable(null)
        }
```

```kotlin
package se.lublin.mumla.chat

import android.graphics.Bitmap
import android.util.Base64
import java.io.ByteArrayOutputStream
import java.net.URLEncoder

/**
 * Turns a prepared bitmap into the `<img src="data:image/jpeg;base64,PAYLOAD">` element Mumble clients
 * exchange. The payload is percent-encoded, which is what `HtmlUtils.percentDecode` and
 * `ImageSource.parse` undo on the receiving side.
 */
object OutgoingImageEncoder {
    const val START_QUALITY = 97
    const val QUALITY_STEP = 10

    /**
     * JPEG-compresses [bitmap], lowering the quality until the base64 payload fits
     * [maxMessageLength] (the server's `ImageMessageLength`; 0 means no limit).
     * Returns null when even the lowest quality does not fit.
     */
    fun compressToFit(bitmap: Bitmap, maxMessageLength: Int): ByteArray? {
        var quality = START_QUALITY
        while (quality > 0) {
            val stream = ByteArrayOutputStream()
            if (bitmap.compress(Bitmap.CompressFormat.JPEG, quality, stream)) {
                val compressed = stream.toByteArray()
                if (maxMessageLength == 0 || base64Length(compressed.size) < maxMessageLength) {
                    return compressed
                }
            }
            quality -= QUALITY_STEP
        }
        return null
    }

    fun imageHtml(jpeg: ByteArray): String {
        val base64 = Base64.encodeToString(jpeg, Base64.NO_WRAP)
        return "<img src=\"data:image/jpeg;base64," + URLEncoder.encode(base64, "UTF-8") + "\"/>"
    }

    /** [compressToFit] + [imageHtml]; null when the image cannot be made to fit. */
    fun encode(bitmap: Bitmap, maxMessageLength: Int): String? =
        compressToFit(bitmap, maxMessageLength)?.let { imageHtml(it) }

    private fun base64Length(byteCount: Int): Int = 4 * (byteCount / 3) + 4
}
```

```kotlin
package se.lublin.mumla.chat

import android.content.Context
import android.graphics.Bitmap
import android.graphics.ImageDecoder
import android.graphics.Matrix
import android.net.Uri
import androidx.exifinterface.media.ExifInterface
import kotlinx.coroutines.CoroutineDispatcher
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import se.lublin.mumla.util.BitmapUtils
import java.io.ByteArrayInputStream
import java.io.IOException
import java.nio.ByteBuffer

/**
 * Prepares a picked image for sending: reads the bytes once, decodes them sampled down to the
 * outgoing bounds with [ImageDecoder], applies the EXIF orientation and fits the result into
 * [maxWidth] x [maxHeight]. Nothing here touches the main thread.
 */
class OutgoingImagePreparer(
    private val context: Context,
    private val maxWidth: Int = MAX_WIDTH,
    private val maxHeight: Int = MAX_HEIGHT,
    private val ioDispatcher: CoroutineDispatcher = Dispatchers.IO,
    private val decodeDispatcher: CoroutineDispatcher = Dispatchers.Default,
) {

    /** Null when the URI cannot be read or does not hold an image. */
    suspend fun prepare(uri: Uri): Bitmap? {
        val bytes = withContext(ioDispatcher) {
            try {
                context.contentResolver.openInputStream(uri)?.use { it.readBytes() }
            } catch (e: IOException) {
                null
            }
        } ?: return null
        return withContext(decodeDispatcher) { decode(bytes) }
    }

    /** The CPU half of [prepare]: blocking, no I/O, safe to call from any background thread. */
    fun decode(bytes: ByteArray): Bitmap? {
        var flipped = false
        var rotationDegrees = 0
        try {
            val exif = ExifInterface(ByteArrayInputStream(bytes))
            flipped = exif.isFlipped
            rotationDegrees = exif.rotationDegrees
        } catch (e: IOException) {
            // No or broken EXIF: treat the image as upright.
        }

        val decoded = try {
            ImageDecoder.decodeBitmap(ImageDecoder.createSource(ByteBuffer.wrap(bytes))) { decoder, info, _ ->
                val sample = BoundedBitmapDecoder.sampleSizeFor(
                    info.size.width, info.size.height, maxWidth, maxHeight
                )
                decoder.setTargetSize(
                    (info.size.width / sample).coerceAtLeast(1),
                    (info.size.height / sample).coerceAtLeast(1),
                )
                // A hardware bitmap cannot be transformed by Bitmap.createBitmap with a Matrix.
                decoder.allocator = ImageDecoder.ALLOCATOR_SOFTWARE
                decoder.isMutableRequired = false
            }
        } catch (e: IOException) {
            // ImageDecoder.DecodeException is an IOException, so this covers "not an image" too.
            return null
        }

        val oriented = orient(decoded, flipped, rotationDegrees)
        return BitmapUtils.resizeKeepingAspect(oriented, maxWidth, maxHeight)
    }

    companion object {
        const val MAX_WIDTH = 600
        const val MAX_HEIGHT = 400

        /** Applies the EXIF orientation; returns [bitmap] itself when there is nothing to do. */
        fun orient(bitmap: Bitmap, flipped: Boolean, rotationDegrees: Int): Bitmap {
            if (!flipped && rotationDegrees == 0) return bitmap
            val matrix = Matrix()
            // Flip first, then rotate, as ExifInterface.getRotationDegrees() documents.
            if (flipped) matrix.postScale(-1f, 1f, bitmap.width / 2f, bitmap.height / 2f)
            if (rotationDegrees != 0) matrix.postRotate(rotationDegrees.toFloat())
            return Bitmap.createBitmap(bitmap, 0, 0, bitmap.width, bitmap.height, matrix, false)
        }
    }
}
```

```kotlin
package se.lublin.mumla.chat

import org.jsoup.Jsoup
import org.jsoup.nodes.TextNode

/**
 * Flattens a Mumble HTML message body into one short plain-text line for a notification.
 * Images become [imagePlaceholder] — otherwise a `data:` URI would put tens of thousands of base64
 * characters into the notification — and the result is truncated to [MAX_LENGTH].
 */
object NotificationText {
    const val MAX_LENGTH = 120

    fun strip(html: String, imagePlaceholder: String): String {
        val document = Jsoup.parseBodyFragment(html)
        document.select("img").forEach { it.replaceWith(TextNode(imagePlaceholder)) }
        document.select("br").forEach { it.replaceWith(TextNode(" ")) }
        val text = document.body().text().replace(WHITESPACE, " ").trim()
        return if (text.length <= MAX_LENGTH) text else text.take(MAX_LENGTH - 1).trimEnd() + "…"
    }

    private val WHITESPACE = Regex("\\s+")
}
```

```kotlin
package se.lublin.mumla.service

import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import androidx.core.app.NotificationCompat
import androidx.core.app.NotificationManagerCompat
import se.lublin.humla.model.IMessage
import se.lublin.mumla.R
import se.lublin.mumla.app.DrawerAdapter
import se.lublin.mumla.app.MumlaActivity

/**
 * A heads-up notification for unread chat messages, augmenting [MumlaConnectionNotification].
 */
class MumlaMessageNotification(
    private val context: Context,
    private val replyHandler: ReplyHandler,
) {
    /** Receives the text typed into the notification's inline reply. */
    fun interface ReplyHandler {
        fun onReply(text: String)
    }

    private val unreadMessages = mutableListOf<IMessage>()

    /**
     * Shows the notification, appending [message] if one is already visible.
     */
    fun show(message: IMessage) {
        unreadMessages += message

        val style = NotificationCompat.InboxStyle()
        style.setBigContentTitle(
            context.resources.getQuantityString(
                R.plurals.notification_unread_many, unreadMessages.size, unreadMessages.size
            )
        )
        for (unread in unreadMessages) {
            style.addLine(context.getString(R.string.notification_message, unread.actorName, line(unread)))
        }

        val channelListIntent = Intent(context, MumlaActivity::class.java)
            .putExtra(MumlaActivity.EXTRA_DRAWER_FRAGMENT, DrawerAdapter.ITEM_SERVER)
        // FLAG_CANCEL_CURRENT ensures that the extra always gets sent.
        val pendingIntent = PendingIntent.getActivity(
            context, 0, channelListIntent,
            PendingIntent.FLAG_CANCEL_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )

        val channelName = context.getString(R.string.messageReceived)
        val channel = NotificationChannel(CHANNEL_ID, channelName, NotificationManager.IMPORTANCE_DEFAULT)
        context.getSystemService(NotificationManager::class.java).createNotificationChannel(channel)

        val builder = NotificationCompat.Builder(context, CHANNEL_ID)
            .setPriority(NotificationCompat.PRIORITY_HIGH)
            .setSmallIcon(R.drawable.ic_stat_notify)
            .setContentIntent(pendingIntent)
            .setAutoCancel(true)
            .setContentTitle(message.actorName)
            .setContentText(line(message))
            .setVibrate(VIBRATION_PATTERN)
            .setStyle(style)
        if (unreadMessages.isNotEmpty()) builder.setNumber(unreadMessages.size)

        NotificationManagerCompat.from(context).notify(NOTIFICATION_ID, builder.build())
    }

    /** Dismisses the notification, marking all messages read. */
    fun dismiss() {
        unreadMessages.clear()
        NotificationManagerCompat.from(context).cancel(NOTIFICATION_ID)
    }

    /** One plain, bounded line for [message]; see spec D5. */
    private fun line(message: IMessage): String = message.message

    private companion object {
        const val NOTIFICATION_ID = 2
        const val CHANNEL_ID = "message_channel"
        val VIBRATION_PATTERN = longArrayOf(0, 100)
    }
}
```

```kotlin
    private fun replyAction(): NotificationCompat.Action {
        val label = context.getString(R.string.notification_reply)
        val replyIntent = Intent(ACTION_REPLY).setPackage(context.packageName)
        // FLAG_MUTABLE is required: the system fills the typed text into this intent.
        val pending = PendingIntent.getBroadcast(
            context, 0, replyIntent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_MUTABLE,
        )
        return NotificationCompat.Action.Builder(R.drawable.ic_action_send, label, pending)
            .addRemoteInput(RemoteInput.Builder(KEY_REPLY).setLabel(label).build())
            .setSemanticAction(NotificationCompat.Action.SEMANTIC_ACTION_REPLY)
            .setShowsUserInterface(false)
            .build()

    private fun registerReplyReceiver() {
        if (replyReceiverRegistered) return
        ContextCompat.registerReceiver(
            context, replyReceiver, IntentFilter(ACTION_REPLY), ContextCompat.RECEIVER_NOT_EXPORTED,
        )
        replyReceiverRegistered = true
    }

    private fun unregisterReplyReceiver() {
        if (!replyReceiverRegistered) return
        context.unregisterReceiver(replyReceiver)
        replyReceiverRegistered = false
    }
```
